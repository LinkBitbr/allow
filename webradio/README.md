# Minha WebRadio

Este diretório contém um exemplo simples de site para uma webradio. Inclui:

- **index.html**: página principal com player de áudio e programação.
- **style.css**: estilos básicos para o layout.
- **script.js**: pequeno script para enviar a mensagem do formulário de contato.

Para visualizar o site, basta abrir `index.html` em um navegador web.
